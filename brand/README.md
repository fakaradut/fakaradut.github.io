# Moon Arc Works brand

Logo A: a gold crescent (moonlight) on the night sky. No star next to it, so it never reads as a flag or a religious sign.

- Colours: night `#0B1026` → `#18214A`, moonlight gold `#FFE2A3` → `#E9A94B`, text `#E9EDF7`.
- Type: Sora 600 for the name, Sora 400 spaced capitals for "WORKS".
- `node brand/generate.js` renders everything in `out/`:
  - `mark*.svg`: the crescent alone (gradient, dark, light)
  - `icon-1024.png` (social avatars), `icon-512.png` (Google Play developer icon), `apple-touch-icon.png`, `favicon*.svg|png`
  - `wordmark-on-dark|light.svg|png`
  - `play-header-4096x2304.png`: the Google Play developer page header
